# MCP server for sample_input

This directory is a self-contained MCP server generated by
`llm_project_packer --target cowork`. It exposes the bundle in this
export folder to any MCP-aware client (Claude Desktop, Cowork, etc.).

## One-time setup

```powershell
pip install -r requirements.txt
```

## Register the server

Open `cowork_config.json` and merge the `mcpServers.fileslicer_sample_input` entry into
your client's MCP config file (for example `~/.claude/mcp.json` or the
Claude Desktop config), then restart the client.

## Tools provided

- `list_documents` — list manifest rows.
- `get_document` — return one document's full text.
- `search` — SQLite FTS5 keyword search across chunks, ranked by BM25.
- `get_chunk` — return one chunk plus the previous/next chunk ids.
- `get_asset_path` — return the absolute local path of an asset or data file.

Moving or renaming this folder is fine; the server resolves paths at runtime.
If you move it, regenerate `cowork_config.json` or update the `args` path inside
your MCP config to point at the new `server.py` location.
